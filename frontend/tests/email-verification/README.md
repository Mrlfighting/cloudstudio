# 邮箱验证浏览器场景

使用 Node.js 内置 WebSocket/CDP 驱动本机 Microsoft Edge，不增加测试框架或项目依赖。所有 `/api/v1/` 请求均由脚本模拟，不访问真实账号、不发送邮件。

## 运行

1. 在一个终端从 `frontend` 启动 `npm.cmd run dev -- --host 127.0.0.1`。
2. 在另一个终端从 `frontend` 执行：

   ```powershell
   node tests/email-verification/browser-smoke.mjs ../.cache/email-ui-20261021/browser
   ```

脚本使用已安装的 Edge（默认 `C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`），创建独立无头浏览器及临时用户目录。报告、截图和临时文件只写入指定的项目内 `.cache` 目录；结束时关闭本次创建的浏览器。环境限制启动时，需要授予本地测试浏览器进程运行权限。

## 覆盖范围

- 注册邮箱必填、格式、占用及注册后手动登录。
- 独立页与弹窗的登录/验证衔接；上传、下载及浏览器下载拦截后的续接。
- 普通业务请求前置检查、管理员深链、状态失败时拒绝放行。
- 202 与实际发送状态区分、投递轮询、失败/过期、服务端重发倒计时。
- 前导零验证码、错误提示、并发验证门、单次 CSRF 刷新。
- 换绑权限保留、资料更新不再直接提交邮箱。
- 退出、快速换号、旧响应迟到、401 不重放、跨标签页通知及错账号 409。
- 360/390px 布局和未验证用户的本地拼豆能力。

2026-10-21 实测 22 项通过，浏览器运行错误 0。该脚本验证前端交互与接口契约，不能替代真实 SMTP、Session 或后端权限测试；后端已有独立测试及邮件模块部署说明。
